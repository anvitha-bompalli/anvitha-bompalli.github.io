How can we stop people from doomscrolling?

What if social media encouraged people to spend less time scrolling? I redesigned Instagram's interface as a concept to explore how real-time weather information could encourage users to take breaks and engage with the world around them.

Role

Designer & developer

Tools

HTML, CSS, JavaScript, weather API

Type

System Critique, Interaction Design, Web Development

Timeline

Fall 2025

The concept

Try the concept

The problem

Social media platforms are designed to encourage continuous engagement, often making it difficult for users to disconnect. I wanted to challenge this design approach by exploring how Instagram could encourage more intentional usage and promote offline activities.

My approach

  1. System Critique: Examined how Instagram's feed and engagement features encourage continuous scrolling.
  2. Concept Development: Proposed integrating real-time weather information into the platform to encourage users to take breaks.
  3. Interface Design & Development: Recreated an Instagram-inspired interface using HTML, CSS, and JavaScript to demonstrate the concept.
  4. API Integration: Incorporated weather data to support contextual prompts based on users' local conditions.

How it works

  • Weather-Based Nudges: Uses local weather conditions to encourage users to consider stepping outside.
  • Contextual Reminders: Introduces weather information into the familiar social media experience as a prompt to take a break.
  • Familiar Interface: Maintains Instagram's recognizable layout while exploring a different approach to user engagement.

Buff Portal App

How might we make Buff Portal easier to navigate on mobile? We redesigned CU Boulder's student portal to create a more intuitive, accessible, and streamlined experience for students accessing essential university services.

Role

UX Researcher & Designer

Tools

Figma, Miro

Methods

User Interviews, Surveys, Wireframing, Prototyping, Usability Testing

Timeline

Fall 2025

Prototype walkthrough

The problem

Buff Portal provides access to essential student services, including class registration, grades, and degree planning. We wanted to create a mobile-first experience that makes frequently used features easier to find and navigate.

What I did

  1. User Research: Conducted surveys and semi-structured interviews to understand student needs, behaviors, and frustrations with Buff Portal.
  2. Research Synthesis: Analyzed feedback to identify frequently used features and opportunities to improve navigation.
  3. Wireframing & Prototyping: Developed low- and mid-fidelity wireframes before creating an interactive high-fidelity prototype in Figma.
  4. Usability Testing: Gathered feedback through think-aloud testing and iterated on the interface to improve clarity, navigation, and accessibility.

What I learned from users

  • Prioritize essential features: Students preferred quick access to frequently used tools rather than an interface crowded with unnecessary features.
  • Navigation matters: Students valued a simple, organized layout that made important tasks easy to locate.
  • Visual clarity: Feedback highlighted opportunities to improve button contrast and refine background colors.

Design decisions

  • Simplified navigation: Organized essential student services into a mobile-friendly layout to reduce unnecessary complexity.
  • Prioritized core features: Focused on frequently used tools such as class search, grades, and degree planning.
  • Improved visual accessibility: Updated button colors to increase contrast and refined interface elements based on usability feedback.
